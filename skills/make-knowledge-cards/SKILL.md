# 知识卡片生成器（Make Knowledge Cards）

## 概述

把一段文章或笔记转换成一组便于复习的知识卡片。每张卡片只讲一个知识点，帮助用户快速掌握原文的核心内容，而不是复述全文。

## 适用输入

- 用户直接粘贴的文章文本（任意长度、任意主题）。
- 本地 Markdown（`.md`）或纯文本（`.txt`）文件的路径。
- 用户明确要求：生成"知识卡片 / 学习卡片 / 复习卡片"、拆解文章、整理笔记等。

## 不支持（超出范围）

- 网页抓取：不打开、不抓取 URL。若用户只给链接，请其粘贴正文或提供本地文件。
- PDF 文件。
- Anki 导入 / 导出。
- 图形界面生成。
- 输入属于以上情况时，说明暂不支持，并引导用户改用「粘贴文本」或「.md/.txt 文件」。

## 输出格式

默认生成 5～8 张卡片（数量规则见下）。每张卡片使用如下 Markdown 结构：

### 卡片 N：标题
**核心知识**：一句话点出这张卡要讲的那个知识点（定义、结论、原理、关键区别等）。
**简明解释**：用 1～3 句大白话把这个知识点讲清楚，尽量不用术语堆砌。
**例子 / 自测**：给一个具体例子，或一个可以自问自答的小问题。

## 工作流程

1. 读取输入。给的是文件路径就先读文件；粘贴的是文本就直接使用。遇到乱码或读取失败时，请用户重新提供。
2. 通读全文，圈出真正重要的知识点：核心概念、关键结论、因果 / 对比关系、易错点、可迁移的方法或原则。
3. 判断能成卡的知识点数量，按重要性排序，最重要的放前面。
4. 按模板逐张成卡。每张只覆盖一个知识点；同一知识点分散在多处的，合并到一张。
5. 成卡后对照「质量规则」自查，必要时合并、删减、调整顺序。

## 质量规则（必须遵守）

- **一张卡只讲一个知识点**。一个知识点被拆成多张卡的，合并。
- **只保留真正重要的知识**，略过铺垫、例子堆砌、客套话和与主题无关的枝节。
- **去重**：同一知识点在不同段落重复出现时，只保留一张卡，综合各处的说法。
- **不编造**：卡片中的事实必须来自原文，不补充原文没有的结论、数据或出处。
- **数量规则**：目标是 5～8 张。材料充分时尽量给出 5～8 张；材料单薄、知识点不足 5 个时，只做实际数量的卡片（例如 3 张），并在开头用一句话说明「原文要点有限，本次共生成 N 张」。不要为了凑数硬凑卡片。
- **语言**：卡片默认使用原文的语言；用户指定语言时按要求输出。

## 示例

输入（节选）：
> 光合作用是植物、藻类和部分细菌利用光能，把二氧化碳和水转化成有机物并释放氧气的过程，主要发生在叶绿体中。影响光合作用速率的主要因素有光照强度、二氧化碳浓度和温度。

输出：

### 卡片 1：光合作用的定义
**核心知识**：光合作用是利用光能把二氧化碳和水转化为有机物并释放氧气的过程。
**简明解释**：植物、藻类和部分细菌在叶绿体里完成这一过程，把无机物变成有机物，同时放出氧气。
**例子 / 自测**：试着分别指出光合作用的原料和产物各是什么？

### 卡片 2：影响光合作用速率的因素
**核心知识**：光照强度、二氧化碳浓度和温度是影响光合作用速率的主要因素。
**简明解释**：这三者任何一项不足或过量，都可能限制反应速率，成为「瓶颈」。
**例子 / 自测**：阴天光照弱时，光合速率为什么下降？

## 交付说明

输出时先给一句总览（共几张卡片、覆盖什么主题），再按顺序列出全部卡片。若用户要求更少 / 更多卡片、纯文本格式或指定语言，按用户要求调整。
