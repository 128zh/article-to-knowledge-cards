# 知识卡片：费曼学习法

共 5 张卡片，覆盖：核心主张、四步流程、核心价值、适用场景与局限。

### 卡片 1：费曼学习法的核心主张
**核心知识**：费曼学习法以"教"促"学"——讲不清一件事给外行听，就说明自己还没真正理解。
**简明解释**：把"能讲明白"当作"真理解"的检验标准。
**例子 / 自测**：怎么判断自己是否真的理解了一个概念？

### 卡片 2：费曼学习法的四步流程
**核心知识**：选概念写下名称 → 用自己的话讲给外行 → 卡壳处回到资料补学 → 简化表述、用类比替换术语。
**简明解释**：输出 → 找漏洞 → 回炉 → 再简化，循环直到讲透。
**例子 / 自测**：试着按这四步讲一个你最近学过的概念。

### 卡片 3：暴露"流畅性错觉"
**核心知识**：核心价值是暴露"以为自己懂了"的假象——看得懂不等于讲得出，更不等于会用。
**简明解释**：阅读时容易产生"流畅性错觉"，输出才是照妖镜。
**例子 / 自测**："看得懂"和"讲得出"的差别在哪里？

### 卡片 4：适用场景
**核心知识**：适合备考、数理化等需要深入理解的学科，也适合程序员巩固技术概念。
**简明解释**：凡是"要真懂、能运用"的知识都适合。
**例子 / 自测**：背英语单词表适合用费曼学习法吗？

### 卡片 5：费曼学习法的局限
**核心知识**：缺点是比较耗时，不适合纯记忆性内容（如单词表、历史年代）。
**简明解释**：它重在"理解"，对只需死记的内容性价比不高。
**例子 / 自测**：举一类不适合费曼学习法的学习内容。
